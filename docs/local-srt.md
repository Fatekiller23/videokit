# 本地文件 → SRT

规格。每一条都写清楚为什么是这样，以及怎么验证。

## 输入

一个容器文件，或一个装容器的目录。认得的扩展名在 `local.SOURCE_EXTENSIONS`，
覆盖常见视频与音频容器。不认得的扩展名明确拒绝，不交给 ffmpeg 报底层错误。

## 流程

```
源文件 --ffmpeg--> 16 kHz 单声道 16 bit WAV --wave 读成 float32--> faster-whisper --> Segment 列表 --> SRT
```

四步都是确定的，没有分支。中间 WAV 落在临时目录，跑完删掉。视频不进库，也不改源文件。

## 为什么不上平台字幕这条路

本地文件没有平台可问。B 站链路的「有字幕就取」是为平台视频设计的，这里没有对应物，
所以不设 `source` 字段，也不假装有两条来源。

## 为什么用 faster-whisper

英语是 Whisper 的强项。这条链路面对的是本机下载的公开课与讲座，英语占比高。
中文仍然走 B 站链路的 `paraformer-zh`，那条路有 `ct-punc` 内建标点。

## 为什么不把路径直接交给 faster-whisper

它 1.2.1 在 PyAV 19 上必崩。`av.open(..., metadata_errors=...)` 的参数在 PyAV 19
被删掉了。本包用 `wave` 读 WAV 成 float32 数组，走 `model.transcribe(array)`，
整个跳过 `av.open`。详见 `docs/known-issues.md`。

## 切条规则

一条识别段落就是一整句，往往长于两行。规则有三条。

1. 文本超过 `max_chars × max_lines`（默认 42 × 2 = 84 字符）时按词切，切出的每条
   不超上限。时间按字符数按比例分配。
2. 折行用 `textwrap`，只在词边界断，不切断长单词。
3. 相邻条目不允许重叠：下一条的起点不早于上一条的终点。短于 0.4 秒的条目拉长到
   0.4 秒，否则在播放器上闪过看不完。

## 产物的形状

标准 SRT。序号从 1 连续，时间格式 `HH:MM:SS,mmm`，编码 UTF-8 无 BOM。
落点默认是视频旁边的同名 `.srt`，`--out` 改目录。

**编码取 UTF-8。** 播放器与剪辑软件都认这个。不带 BOM，因为带 BOM 时有些播放器
会把 BOM 当成第一个字符显示。

## 跳过与重做

已有 `.srt` 且 mtime 不早于视频时跳过，`--force` 重做。判据是文件时间，不看内容
是否为空：空字幕不该存在，因为「零分段」会当失败处理，不写文件。

## 退出码

| 情况 | 退出码 |
| --- | --- |
| 全部成功，或全部跳过 | 0 |
| 有任何文件失败 | 1 |
| 参数错 | 2 |

失败不中止整批。每个文件的失败原因打印在 stderr，结尾汇总失败清单。

## 设备与显存

`--device auto` 先试 CUDA，起不来退 CPU 并在 stderr 说一句。`large-v3` 在 8 GB
显卡上以 `float16` 跑得下。CPU 上退 `int8`，慢一个数量级。
